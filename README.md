# Urban Bite Kitchen

A responsive restaurant website concept built with HTML, CSS, and vanilla JavaScript. The project presents a casual dining brand with a food-focused landing page, menu categories, customer reviews, gallery, and restaurant information.

## Live Demo

[View Urban Bite Kitchen](https://urban-bite-portfolio.netlify.app)

## Features

- Restaurant landing page with a hero section and featured dishes
- Menu section with category tabs for pizza, burgers, pasta, sides, and drinks
- Popular dishes with food imagery
- Restaurant information, location, and opening-hours section
- Customer testimonials and food gallery
- Contact and order call-to-action links
- Smooth scrolling and scroll-triggered reveal animations
- Responsive layout for different screen sizes

## Built With

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts
- Unsplash images

## Project Structure

```
urban-bite-kitchen/
└── index.html
```

The current version keeps the page structure, styles, and JavaScript in a single HTML file.

## Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/afksuyash/urban-bite-kitchen.git
   ```

2. Open the project folder.
3. Open `index.html` in your browser.

No build tools or package installation are required.

## Project Status

This is a personal frontend portfolio/demo project. It is not an operating restaurant website. The menu, testimonials, address, phone number, and contact details are sample content. The order/contact calls to action are demonstration links; the site does not process orders, payments, or reservations.
